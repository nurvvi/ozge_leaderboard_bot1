# @ozge_leaderboard_bot

Telegram-бот на Python и Aiogram 3.x для форума. Вся активность, игры и проверяемые задания используют единую валюту **ÖZGEcoins**.

## Экономика ÖZGEcoins

| Событие | Награда |
|---|---:|
| Осмысленное текстовое сообщение | +1 |
| Фото | +3 |
| Видео | +5 |
| Голосовое сообщение | +5 |
| Telegram video note / кружок | +5 |
| Победа в игре | +3 |
| Задание дня | указано в JSON задачи |

Баланс хранится в `users.ozgecoins`. Все изменения проходят через единый атомарный сервис и записываются в `ozgecoin_transactions`. Уникальный `unique_key` предотвращает повторное начисление.

Профиль показывает только username и баланс ÖZGEcoins. Лидерборд сортируется по этому же балансу.

## Задания дня

Активное задание детерминированно выбирается по локальной дате `Asia/Almaty` и не меняется в течение дня.

Поддерживаются типы:

- `daily_word` — использование заданного слова в чате без учёта регистра, автоматическая награда один раз в день;
- `daily_question` — непустой текстовый reply на публикацию задания;
- `photo_challenge` — фото в reply на публикацию;
- `video_challenge` — обычное видео или video note в reply;
- `social_task` — автоматической награды нет, администратор может использовать `/award`.

Выполнение хранится в `daily_task_completions` с полями `telegram_user_id`, `task_id`, `task_date`, `transaction_id`. Уникальное ограничение запрещает повторную награду одному пользователю за ту же задачу в тот же день.

### Как добавить daily-задачу

Отредактируйте `data/daily_tasks.json`, не меняя Python:

```json
{
  "id": "daily-word-example",
  "type": "daily_word",
  "word": "кітап",
  "kk": "Бүгін чатта «кітап» сөзін қолдан.",
  "ru": "Используй сегодня слово «кітап» в чате.",
  "reward": 3,
  "active": true
}
```

Для reply-задач поле `word` не требуется. У social-задачи задайте `reward: 0`.

## Игры

Через `/games` доступны:

- Мақалды жалғастыр / Продолжи пословицу;
- Дұрыс па, бұрыс па? / Правда или ложь;
- Қызықты факт / Интересный факт.

В паре `chat_id + topic_id` одновременно работает одна игра. Первый правильный ответ атомарно завершает сессию и получает `+3 ÖZGEcoins`. Повторная награда невозможна. После игры пользователю показываются только победитель, награда и правильный ответ. Ссылки на источники остаются в JSON и базе только для внутренней проверки.

## Игровой JSON-контент

Контент находится вне Python:

- `data/proverbs.json`;
- `data/facts.json`.

Импорт не имеет программного лимита и поддерживает 500+ пословиц и 1000+ фактов. Добавление материалов требует только новых JSON-объектов со стабильным `id`. Python-код менять не нужно. Файл `data/quiz_questions.json` сохранён как архив исходных материалов, но больше не импортируется в игровые режимы.

Для игры используются записи с `active=true`, `verified=true` и заполненным HTTPS `source_url`.

```bash
python scripts/update_content.py
python -m app.content_import --db activity_bot.db
```

Первый скрипт обновляет локальный source-кэш. Второй валидирует JSON и выполняет идемпотентный импорт.

## Чат и тема «Флуд»

```env
FLOOD_CHAT_ID=-1002008854992
FLOOD_TOPIC_ID=1
TIMEZONE=Asia/Almaty
```

Для канала **@ozgeforum** (Özge Forum, форум с темами):
- `FLOOD_CHAT_ID` — ID супергруппы (`-1002008854992`)
- `FLOOD_TOPIC_ID` — ID темы «FLOOD» (`1`)

Бот **молча игнорирует** все сообщения и команды вне этой темы. В других сабтопиках и личке он не отвечает. Админ-команды (`/award`, `/start_game` и т.д.) доступны администратору в личке с ботом или в теме FLOOD.

`FLOOD_TOPIC_ID=0` — основной чат без темы. Для другой темы отправьте `/where` внутри неё, скопируйте `message_thread_id` в `.env` и перезапустите бота.

## Администрирование

- `/award telegram_id amount reason` — начислить ÖZGEcoins;
- `/deduct telegram_id amount reason` — списать;
- `/reset_points telegram_id reason` — обнулить конкретного пользователя компенсирующей транзакцией;
- `/user_info telegram_id` — показать баланс;
- `/cancel_game` — принудительно завершить игру;
- `/start_game game_type` — принудительно запустить игру.

## Production reset

Миграция №5 выполнила одноразовую подготовку к production: сохранила Telegram-пользователей, обнулила их баланс и очистила транзакции, игровые сессии и историю daily-выполнений. Перед текущим запуском существовавшие тестовые профили также были удалены вручную после создания резервных копий; автоматического удаления будущих пользователей нет.

Для осознанного повторного reset используется команда с обязательным подтверждением. Перед очисткой она автоматически создаёт SQLite backup:

```bash
python scripts/reset_production_data.py --db activity_bot.db --confirm RESET
```

## Локальный запуск

Рекомендуется Python 3.11–3.13.

```bash
cd pythonproject
python3.13 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
set -a
source .env
set +a
python main.py
```

`Procfile` запускает:

```text
worker: python main.py
```

В deployment подключите persistent volume к директории базы и передайте `BOT_TOKEN`, `FLOOD_CHAT_ID`, `FLOOD_TOPIC_ID`, `ADMIN_IDS`, `DB_PATH`, `TIMEZONE` через environment variables.
